## What's new in Foxlator 0.10.2

**LedgerFox is now Foxlator**
- The app, the install files and the website now carry the Foxlator name: `Foxlator-Setup-x64.exe`, `Foxlator-mac-*.dmg`, `Foxlator-linux-x86_64.AppImage` and `Foxlator-android.apk`.
- The website is now **foxlator.niyazio.com**. Old ledgerfox.niyazio.com links open the same page on the new address.
- Already installed? The app updates itself as usual, and your sign-in, settings and data stay as they are.
- New Foxlator logo.
